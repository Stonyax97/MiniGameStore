# MiniGameStore
A small Python terminal game store that I started as a learning project.

I originally created it as a simple exercise to practice dictionaries. As I learnt new Python concepts, It just felt natural to keep implementing them into the project.

The goal is simple: learn as i go while keeping a record of my progress.

## What I've Learned Through This Project

Some of the Python concepts I've practiced include:

- Variables and data types
- Conditionals and loops
- Functions
- Lists and dictionaries
- Error handling
- File I/O
- JSON
- Keyboard input with `msvcrt` (Windows only)
- Organizing a project into multiple files

## Version History

Each version represents a stage of my learning. This repo is for keeping records and seeing changes.

## Project Status

This project is mainly for learning and experimentation.
It is not intended to be a serious game store or production application.
More features and improvements will be added as I learn more Python.
It just seemed super natural for me to add my new knowledge onto this project as I get new ideas.

"Learn as you go" is what this project seems like to me.
